# Installation

## Download

```sh
corepack enable pnpm
git clone git@github.com:ethanneff/playground-react-native.git
cd example
pnpm install
bundle install
cd ios
pod install
pnpm ci-env-vars
```

## Run

```sh
pnpm start
```

```sh
pnpm web
```

## Lint

```sh
pnpm lint
```

## Test

```sh
pnpm test
```

## Deploy

```sh
pnpm build
```
